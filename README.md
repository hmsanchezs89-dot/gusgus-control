# GUS GUS CONTROL MVP

App lista para probar en local y subir a Vercel.

## Instalar
```bash
npm install
npm run dev
```

## Para nube
1. Crear proyecto en Supabase.
2. Copiar `.env.example` a `.env.local`.
3. Poner las llaves de Supabase.
4. Ejecutar SQL de `supabase.sql`.
5. Subir a GitHub y conectar a Vercel.
