# GUS GUS CONTROL ADMIN

Versión con:

- Caja
- Descuento en pesos
- Eliminar artículos del carrito
- Productos: crear, modificar y eliminar
- Inventario: crear, modificar y eliminar
- Compras: crear, modificar y eliminar
- Mermas: crear, modificar y eliminar
- Gastos
- Ventas
- SAT
- Corte semanal jueves-lunes

## Antes de usar

Ejecuta `supabase-admin.sql` en Supabase SQL Editor.
